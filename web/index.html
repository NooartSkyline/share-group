      เร็วกว่า Wi-Fi เพราะวิ่งบน USB โดยตรง ไม่ต้องติดตั้งแอป เสียบสายแล้วเปิด USB tethering (Android) หรือ Personal Hotspot แบบ USB (iPhone)

      ยังไม่พบสาย

      1. เสียบสาย USB เข้า Mac (บน iPhone กด Trust ถ้าถาม)
      2. Android: ตั้งค่า → เครือข่ายและอินเทอร์เน็ต → USB tethering / จุดเชื่อมต่อทาง USB
      3. iPhone / iPad: ตั้งค่า → Personal Hotspot แล้วให้ Mac เชื่อมผ่าน USB
      4. จากนั้นเปิดเบราว์เซอร์บนมือถือที่เสียบสาย แล้วพิมพ์ที่อยู่ที่แสดงที่นี่
